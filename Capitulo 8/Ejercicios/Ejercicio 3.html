a) Error: El punto y coma después de while termina la instrucción. Además, falta inicializar correctamente x y el incremento debe estar dentro del ciclo.

Código corregido:

var x = 1;
while (x <= 10)
{
    ++x;
}

b) Error: Falta break en el case 1, default debe llevar dos puntos y document.writeln está escrito incorrectamente.

Código corregido:

switch (n)
{
    case 1:
        document.writeln("El número es 1");
        break;
    case 2:
        document.writeln("El número es 2");
        break;
    default:
        document.writeln("El número no es 1 ni 2");
        break;
}

c) Error: Falta inicializar n con el operador = y la condición debe permitir imprimir hasta el 10.

Código corregido:

var n = 1;
while (n <= 10)
    document.writeln(n++);
